# Runnable definition

This agent is registered as a Claude Code subagent at `~/.claude/agents/pro-lash-content.md` (global, so it's available in any Claude Code session).

**To run it:** ask Claude to use the `pro-lash-content` subagent for a caption, content idea batch, or posting calendar — e.g. "draft 5 caption ideas for the founder-story photo" in a Pro Lash project session.

**What it can touch:** nothing. Read-only, draft-only. No Instagram/TikTok/scheduler MCP is connected in this build.

See `spec.md` in this folder for the full role, voice, allowlist, and escalation rules.
