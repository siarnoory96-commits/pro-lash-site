# Runnable definition

This agent is registered as a Claude Code subagent at `~/.claude/agents/pro-lash-engagement.md` (global, so it's available in any Claude Code session).

**To run it:** paste a real DM/comment and ask Claude to use the `pro-lash-engagement` subagent, or just say "draft a reply to this: [paste]" in a Pro Lash project session — it'll route there.

**What it can touch:** nothing. Read-only, draft-only. No Instagram/TikTok MCP is connected in this build, so every output is a hand-off draft, never an auto-send.

See `spec.md` in this folder for the full role, voice, allowlist, and escalation rules.
